## Illustration, 2026-09-21

The banners now carry a **Basin and Range horizon** built from the badge's own geometry: layered ridges whose peaks use the mountain's exact slope (154 run / 222 rise), the nearest ridge carrying the same snow notch as the mark. Depth comes from tonal steps along the ramp — warm neutral haze far, cool brand tints near — not from gradients or shadows, which §4 of the brand system bans. It is generated by `scripts/collateral/banner-art.ts` from a fixed seed, so a rebuild is byte-identical, and it is wrapped in `<g data-art="ridges">` so the identity lock can tell brand illustration from a redrawn mark.

The field is always anchored bottom-left and stops short of the safe zone, so it never touches the lockup or the type. On every platform that puts an avatar or page logo over the left of the banner, the illustration is what sits under it — decorative, so occlusion costs nothing.

**Two sets ship:**

| Set | Files | Use |
|---|---|---|
| Light | `{platform}-{w}x{h}.png` | The default. Warm surface, navy lockup. |

Both at 1× and 2×, both with safe-zone overlays. Rebuild either with `node scripts/build-daniel-banners.ts [--theme dark] [--suffix -dark] [--art none]`; `--art none` returns the plain typographic version.

## No photography, and why

No photograph was added. Two reasons, both worth stating plainly.

The category convention — a stock photo behind a dark overlay, a gradient wash, a shield or umbrella icon — is banned by name in §11 of the brand system, and it is what nearly every insurance banner template does. Copying it would make this agency look like the others.

More practically, there is no licensed photography to use. §8 of the brand guide is specific about what a Desert Peak photograph is: documentary, real places in the four states under hard horizontal light, the buildings people actually insure, no stock. That is a commissioning job, not something to fake. When the client supplies licensed images, the generator takes a photo slot without redesign: the ridge field is one call in `build-daniel-banners.ts` and an image layer drops into the same place, with the text staying inside the safe zone.
